# SupportLogic

> SupportLogic provides AI infrastructure for customer experience (CX/service
> experience). Its Service Experience Data Cloud normalizes support data (cases,
> chat, voice) and enriches it with AI-driven sentiment and predictive signals,
> while ambient AI agents predict escalations, detect sentiment, automate case
> routing, draft replies/knowledge, and coach agents. A first-party hosted MCP
> server exposes this intelligence to MCP clients such as Claude and ChatGPT.

This llms.txt was GENERATED by the API Evangelist enrichment pipeline from the
SupportLogic public web surface and the artifacts in this repository. SupportLogic
publishes no public OpenAPI specification; its programmatic surface is the hosted
MCP server.

## Platform
- [MCP Server](https://www.supportlogic.com/platform/mcp-server/): Hosted, tenant-scoped MCP server (JSON-RPC 2.0, bearer token) with ~16 tools across Account Context, Case Intelligence, Knowledge & Resolution, and Signals & Alerts.
- [Integrations](https://www.supportlogic.com/how-it-works/integrations/): Connectors into existing support/CRM stacks.
- [Product Tours](https://www.supportlogic.com/how-it-works/product-tours/)
